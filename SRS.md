# Pharmacy Starter - Short SRS

## Purpose
Provide a minimal starter system for retail+wholesale pharmacy operations focusing on billing, inventory, and basic compliance.

## Key Features (MVP)
- Fast billing POS
- Product master
- Batch-wise inventory with expiry date
- Purchase receipts (GRN)
- Sale creation with FEFO deduction
- GST-ready fields in product master

## Non-Functional
- Deployable on a single node
- Uses sqlite for quick start
- Simple REST API for frontend integration
